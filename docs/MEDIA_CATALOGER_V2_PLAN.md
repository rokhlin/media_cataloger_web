# План разработки Media Cataloger V2

## 1. Анализ текущей системы (V1)
Существующая архитектура состоит из трех основных компонентов:
- **Media Cataloger (Backend)**: Управляет путями к медиа, базой данных метаданных, запуском фоновых задач.
- **Media Cataloger Web (UI)**: React 19 интерфейс для галереи, просмотра файлов и семейного древа.
- **AI Engine**: Удаленный или локальный Python-демон (FastAPI), использующий OpenCV, InsightFace, Whisper и LLM для сложного анализа контента (лиц, аудио, описаний).

**Основные проблемы V1:**
- **Производительность UI**: Загрузка большого количества изображений сразу вызывает подвисания браузера.
- **Производительность Backend/AI**: Повторное сканирование неизмененных файлов тратит ресурсы.
- **Устаревший UX/UI**: Необходим современный, отзывчивый интерфейс с асинхронными статусами.

---

## 2. Архитектура и стек технологий V2
Стек технологий остается прежним (React 19 + NestJS + Python AI Engine), однако вносятся ключевые архитектурные и визуальные изменения:
- **UI/UX**: Использование **Tailwind CSS + Headless UI (Shadcn/Radix)** (выбрано как рекомендуемое решение) для создания современного, быстрого и отзывчивого интерфейса.
- **Оптимизация загрузки**: Внедрение "ленивой загрузки" (Lazy Loading) — первоначальная загрузка 100 миниатюр с последующей подгрузкой при скроллинге.
- **Система хеширования**: Комбинированный подход — использование размера файла и даты изменения (mtime) для быстрой проверки, а быстрый хеш (например, xxHash или BLAKE3) вычисляется только при изменении базовых атрибутов. Это решает проблемы производительности без ущерба для точности.
- **База данных**: Метаданные, хеши, транскрипции и лица кэшируются в БД (SQLite) для мгновенного доступа со стороны UI.

## 3. Описание экранов и нового UI/UX

### 3.1. Главная панель навигации (Sidebar / Topbar)
- Кнопки: Домой (Галерея), Семейное древо, Управление дубликатами, Настройки, Админ панель (только для admin).
- Верхний правый угол: Аватар пользователя (профиль/выход) или кнопка Login/Регистрация.
- **Глобальная информационная строка**: Статус-бар (Progress bar), отображающий фоновые процессы (сканирование, анализ AI, поиск дубликатов).

### 3.2. Главный экран (Галерея)
- **Сетка миниатюр**: Первоначально загружает 100 элементов. Подгрузка при прокрутке. Под каждой миниатюрой отображается имя файла.
- **Поиск и фильтрация**:
  - Текстовый поиск по ключевым словам (поиск по сгенерированным AI описаниям и тегам).
  - Группировка и фильтрация по дате, типу файла (фото/видео), местоположению, распознанным лицам.
- Клик по миниатюре открывает **Просмотр медиафайлов**.

### 3.3. Экран: Просмотр медиафайлов
- Полноэкранный режим с возможностью воспроизведения (если видео).
- **Метаданные (сбоку/снизу)**: Имя, тип файла, EXIF-данные, описание от AI, распознанные лица, связь с семейным древом.
- **Панель быстрых действий**: Удалить, Переместить, Запустить AI-сканирование заново.
- Кнопка "Закрыть" (возврат в галерею с сохранением позиции скролла).

### 3.4. Экран: Семейное древо
- Визуальное графовое отображение генеалогического дерева с карточками членов семьи.
- Если древо пустое — отображается заглушка с кнопкой "Добавить корневого пользователя".
- Поддержка связывания карточек персон с распознанными лицами (из V1).

### 3.5. Экран: Управление дубликатами
- Галерейный вид для сравнения файлов (с указанием путей, размеров, даты).
- **Вкладки**:
  1. Серии снимков.
  2. Найденные дубликаты.
  3. Архив удаленных файлов (корзина).
- Массовый выбор файлов для удаления с обязательным **модальным окном подтверждения**.
- Клик на серию открывает просмотр всех кадров серии. Логика объединения в серии наследуется из V1.

### 3.6. Экран: Настройки
- **AI Конфигурация**: Ввод токенов (Gemini/другие провайдеры), настройка подключения к AI Engine.
- **Темы и UI**: Настройка визуального отображения (светлая/темная тема, плотность сетки).
- **Семейное древо**: Правила формирования.
- **Дубликаты**: Настройка чувствительности поиска дубликатов и серий.

### 3.7. Экран: Админ панель (только для Администраторов)
- **Управление пользователями**: Создание, блокировка, смена ролей, принудительный сброс пароля (система генерирует случайный пароль или администратор вводит вручную -> отправка на Email).
- **Feature Flags**: Включение/отключение функционала в реальном времени (логика из V1).
- **Глобальные настройки UI**: Сохранение конфигурации внешнего вида на сервере, которая применяется ко всем остальным клиентам (не-администраторам) при их входе.

## 4. Описание базового фонового функционала

### 4.1. Регистрация и онбординг
- При первом запуске требуется регистрация.
- Пошаговый Wizard (инструкция) для настройки:
  - Ввод пути к локальным медиафайлам.
  - Ввод API-токенов для AI-моделей.

### 4.2. Механизм сканирования и хеширования
- После настройки путей запускается первоначальное сканирование.
- **Хеширование**: Применяется комбинированный алгоритм. Система ежедневно сверяет размер файла и `mtime`. При несовпадении вычисляется легкий хеш (xxHash/BLAKE3) для подтверждения изменений. Это кардинально снижает нагрузку на дисковую подсистему и предотвращает повторный анализ файлов AI-движком.
- **Генерация кэша**: Создаются миниатюры (thumbnails) в отдельной папке для мгновенной отдачи в UI галерею.
- **Фоновый Job-менеджер**: Ежедневный cron-job (или File Watcher) проверяет папку на наличие новых/удаленных файлов, пересчитывает хеши и обновляет БД.

### 4.3. Интеграция с AI Engine
- **Фото**: Извлечение EXIF, определение лиц, поиск совпадений лиц в БД. Незнакомым лицам присваивается временное имя (например, `Person_001`), которое пользователь может позже переименовать или удалить.
- **Видео**: Извлечение аудиодорожки -> Whisper (транскрипция) -> LLM (выделение ключевых слов и смысла видео).
- Все результаты сохраняются в БД.

## 5. План поэтапной реализации

1. **Этап 1: Подготовка инфраструктуры и БД**
   - Внедрение системы хеширования в `media_catalog` (Backend).
   - Настройка cron-задач для ежедневного сканирования.
   - Обновление схем БД (хранение хешей, паролей, ролей пользователей).

2. **Этап 2: Редизайн UI (База и Галерея)**
   - Установка и настройка Tailwind CSS + Shadcn в проекте `media_cataloger_web`.
   - Разработка нового Layout (навигация, статус-бар).
   - Создание компонента Галереи с виртуализацией/ленивой загрузкой (первые 100 элементов) и фильтрами.
   - Создание компонента Просмотра медиафайла.

3. **Этап 3: Функциональные модули**
   - Интеграция Семейного древа (перенос из V1 с новым дизайном).
   - Интеграция интерфейса управления дубликатами и сериями снимков.

4. **Этап 4: Настройки, Админ панель и Auth**
   - Реализация экрана авторизации, онбординга и настроек AI.
   - Разработка Админ панели (управление пользователями, Feature Flags, глобальные UI-конфиги).

5. **Этап 5: Тестирование и оптимизация**
   - Тестирование на больших коллекциях файлов (10k+).
   - Оптимизация ответов AI Engine и скорости отдачи миниатюр.
